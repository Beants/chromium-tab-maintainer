# Security

Do not publish tokens, original private URLs, browser storage dumps or personal browsing history in an issue.

Report a vulnerability through [GitHub's private vulnerability reporting](https://github.com/Beants/chromium-tab-maintainer/security/advisories/new) when available. Include the affected version, minimal reproduction using fictional sites, and the expected protection behavior. Do not rely on a response-time guarantee.

The current release is intended for local installation. Review [PRIVACY.md](PRIVACY.md) for permission scope and storage limits.
