# Chromium Tab Maintainer · 标签页自动整理

本机运行的 Chromium Manifest V3 扩展。无需服务端、API Key 或 LLM；无遥测。安装后默认暂停。

[下载最新版](https://github.com/Beants/chromium-tab-maintainer/releases/latest) · [English](README.md) · [隐私说明](PRIVACY.md)

## 安装

1. 下载 Release 中的 ZIP 并解压，或克隆仓库。
2. 打开浏览器扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”。
3. 选择含 `manifest.json` 的解压目录，或源码中的 `extension/`。
4. 点击插件图标，先预览；用两个窗口的临时测试页核对隔离、恢复和排序。
5. 确认后勾选“窗口隔离测试已完成”。可启用每小时自动维护，也可直接点“立即整理一次”。

**整理范围是当前配置文件中各个窗口，不只是设置页所在窗口。** 各窗口单独处理，不跨窗口合并或移动。Chrome 121+ 为目标基线；Edge/Brave 等需具备相同 API 并自行验证。开发期核心实现的实机验收来自 Ego Lite；此公开构建已通过自动化检查，不能据此声称所有 Chromium 衍生浏览器都已实测。带 Space/工作区的浏览器须先核对它与 `windowId` 的映射。

## 整理规则

| 规则 | 行为 |
| --- | --- |
| Git 项目 | 每个窗口内，同 Git 主机及端口、同完整仓库路径，保留最近访问的一页；其他安全页关闭，不等天数。不同命名空间、主机和窗口分别保留。 |
| 普通网址去重 | 忽略名为 `id` 的查询参数和路径纯数字段，再用网址双向包含匹配，保留最新打开页；打开时间未知时按最近访问回退。 |
| 同域名页 | 去重后同完整主机名仍有多页时，保留最近访问页，其他至少 24 小时未访问的安全页关闭。 |
| 即时清理 | 明确休眠页、已识别错误页、百度首页、浏览器内置 New Tab，在每小时检查或手动运行中直接清理，无 1 天/7 天年龄限制。 |
| 临时页 | 明确搜索结果、部分公共站点主题/介绍页及登录中转等，至少 24 小时未访问可关闭，即使仅此一页。精确范围见 `extension/temporary.js`。 |
| 常规过期 | 其他符合保护条件的页面默认 7 天未访问后关闭，可设置 1–365 天。已识别 Git 项目保留页不按这条删除，休眠/错误规则仍优先。 |
| 排序 | 按站点别名、项目、主机名整理；固定页置前。已有分组/分屏的窗口保留原顺序。 |

`/merge_requests/123` 与 `/merge_requests/456` 可被视作重复，`/v1`、UUID、其他查询参数和片段不被忽略。原始网址始终用于实际关闭记录及恢复。

固定、当前使用、已知未保存输入、媒体/捕获、白名单、分组/分屏、未知活页面状态及恢复冷却会阻止关闭，因此受保护时可能暂留多页。无法全局发现所有外部录屏/共享，必要时点“立即暂停”。

## 手动操作与进度

顶部操作栏滚动时保持可见。运行中显示检查、清理、排序阶段，以及已处理数量、确认关闭/调整数量和异常。检查时不编造总百分比；无任务时明确显示 0 项。

“立即整理一次”跳过自动维护的暂停、空闲及交互/观察 30 秒等待，但保留窗口验证与内容保护，不改变自动开关。运行中再点暂停、继续操作网页或修改保护状态，会取消后续操作。按钮不会把浏览器关闭失败、worker 中断或恢复异常误报为成功。

## 自定义与隐私

公开版不含内网站点、私人项目和浏览记录。Git 默认别名只有 GitHub/GitLab；自建服务请在 JSON 别名中加入完整主机名。项目规则仅用于排序，白名单按完整主机名匹配。兼容保留的旧只读路径字段不限制清理范围。

关闭记录仅在本机保存 30 天，可恢复单页或整批。恢复只重新打开网址，无法还原页面内输入；恢复页有 24 小时冷却。存储未由本扩展加密，完整网址可能带查询参数和片段，请参阅 [PRIVACY.md](PRIVACY.md)。
